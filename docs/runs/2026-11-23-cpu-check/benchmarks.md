# Benchmarks

Generated by `go run ./cmd/bench bench/raw docs/benchmarks.md` from the raw results in [bench/raw](../bench/raw); do not edit by hand.

**Read this first.** The numbers come from one shared-tenancy cloud VM running a kind cluster, with the workload on two pinned CPUs of one node. They compare the configurations with each other on that machine and say nothing about any other. Each cell is the median of its runs, with the minimum and maximum in brackets; a wide bracket means the cloud VM's noise was large next to the difference being measured.

Sensor CPU is the sensor's processes on the workload's node, in percent of one CPU over the run; memory is their resident set at the end of the run. Events per second and drops are Tephra's own kernel counters.
